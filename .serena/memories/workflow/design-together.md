# Design work is done together, one step at a time

For UI design (Claude Design canvas) and other design or brainstorming work, don't run ahead and build everything in one go. Agree each step with the user first: the screens, then the look, then each screen. Ask one question at a time and wait for the answer before drawing.

**Why:** On 2026-09-23, starting the swipe-game-ui design, I created the canvas, pulled data, and started laying out 8 screens and a visual style without asking. The user stopped me: "we need to do it together... you run too fast again".

**How to apply:** This covers design and decisions. Routine mechanics like commits don't need approval (see `mem:workflow/approval-means-commit`). Before drawing anything, confirm scope and direction. After drawing one screen, show it and get feedback before the next.
